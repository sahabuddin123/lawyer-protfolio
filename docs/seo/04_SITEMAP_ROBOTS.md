# XML Sitemap & Robots.txt Architecture — Advocate Nijam Uddin (Haq)

### 1. XML Sitemap Architecture (`/sitemap.xml`)
The XML sitemap is dynamically generated by `App\Services\SitemapService` and served via `App\Http\Controllers\Api\V1\Public\SitemapController`.

#### Technical Specification:
- **URL**: `https://nijamuddin.com/sitemap.xml`
- **Root Tag**: `<urlset xmlns="http://www.sitemaps.org/schemas/sitemap/0.9" xmlns:xhtml="http://www.w3.org/1999/xhtml">`
- **Response Header**: `Content-Type: application/xml; charset=UTF-8`
- **Robots Header**: `X-Robots-Tag: noindex, follow` (to instruct engines not to index the sitemap XML itself as a content page, but follow all child URLs).
- **Caching**: Fully cached via `CmsCacheService::sitemapKey()` (`cms:sitemap:xml`) for 24 hours, automatically invalidated on publish/unpublish/update/delete events.

#### Included Modules & URL Filters:
Only records satisfying **`status = 'published'`** AND **`visibility = 'public'`** (or equivalent) are indexed:
1. **Core Static Pages**: `/`, `/about`, `/practice-areas`, `/courtroom`, `/research`, `/judgments`, `/publications`, `/media`, `/videos`, `/gallery`, `/contact`.
2. **Practice Areas**: `/practice-areas/{slug}` (`priority: 0.9`, `changefreq: weekly`)
3. **Courtroom Experiences**: `/courtroom/{slug}` (`priority: 0.8`, `changefreq: monthly`)
4. **Judgment Reviews**: `/judgments/{slug}` (`priority: 0.8`, `changefreq: monthly`)
5. **Legal Research**: `/research/{slug}` (`priority: 0.8`, `changefreq: monthly`)
6. **Publications**: `/publications/{slug}` (`priority: 0.7`, `changefreq: monthly`)
7. **Broadcast Videos**: `/videos/{slug}` (`priority: 0.7`, `changefreq: monthly`)
8. **Press Coverage**: `/media/{slug}` (`priority: 0.7`, `changefreq: monthly`)
9. **Media Appearances**: `/media/{slug}` (`priority: 0.7`, `changefreq: monthly`)
10. **Gallery Albums**: `/gallery/{slug}` (`priority: 0.6`, `changefreq: monthly`)
11. **Custom CMS Pages**: `/{slug}` (`priority: 0.5`, `changefreq: monthly`)

#### Authentic Lastmod:
The `<lastmod>` tag strictly pulls the database record `updated_at->toIso8601String()`. Dates are never fabricated or defaulted to the current timestamp.

### 2. Robots.txt Architecture (`/robots.txt`)
Served dynamically by `RobotsController` at `/robots.txt` and mirrored statically in `frontend/public/robots.txt`.

#### Content:
```txt
User-agent: *
Allow: /
Allow: /build/
Allow: /assets/
Allow: /images/

Disallow: /admin/
Disallow: /api/
Disallow: /storage/secure/
Disallow: /storage/confidential/
Disallow: /login

Sitemap: https://nijamuddin.com/sitemap.xml
```

#### Crawler Protection Rules:
1. Public assets (CSS, JS, WebP images) are explicitly allowed so modern search engines can render pages accurately without rendering penalties.
2. Internal administrative endpoints, consultation records, and confidential PDFs (`/storage/secure/*`) are blocked.
3. The dynamic sitemap URL is declared at the bottom of the robots directive.
