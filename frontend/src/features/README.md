# Domain Features Architecture

This directory organizes module-specific logic, hooks, state, and domain components for future implementation phases:

- `about/` — Advocate biography, academic credentials, chamber timeline
- `practice-areas/` — Legal specializations, jurisdiction filters
- `courtroom/` — Litigation briefs, case records, appellate arguments
- `judgments/` — Precedent analysis, ratio decidendi reviews
- `research/` — Academic monographs, journal publications
- `publications/` — Books, law review articles, PDF downloads
- `media/` — National press commentary, television appearances
- `videos/` — Judicial lecture archive, seminar recordings
- `gallery/` — Bar event albums, milestone photo masonry
- `consultation/` — Client intake forms, chamber appointment bookings

All foundational UI primitives from `components/` are shared across these features.
